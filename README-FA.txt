CodeNova Pro — سایت تیم برنامه‌نویسی با پنل مدیریت سمت سرور

امکانات:
- صفحه اصلی واکنش‌گرا
- پنل مدیریت وروددار
- مدیریت تنظیمات و متن‌های سایت
- افزودن/ویرایش/حذف خدمات
- افزودن/ویرایش/حذف نمونه‌کارها و آپلود تصویر
- افزودن/ویرایش/حذف اعضای تیم و تصویر هر عضو
- فرم تماس و دیدن پیام‌های ثبت‌شده
- ذخیره اطلاعات در پایگاه داده SQLite
- رمز عبور هش‌شده با bcrypt
- محدودیت تلاش ورود، کوکی نشست HttpOnly و محدودیت نوع/حجم تصویر

پیش‌نیاز:
Node.js نسخه 18 یا بالاتر

راه‌اندازی در کامپیوتر:
1) Node.js را نصب کن.
2) این پوشه را در ترمینال باز کن.
3) دستور npm install را اجرا کن.
4) فایل .env.example را به .env تغییر نام بده.
5) داخل .env، SESSION_SECRET را با یک مقدار تصادفی طولانی عوض کن و برای ADMIN_PASSWORD یک رمز قوی بگذار.
6) دستور npm start را اجرا کن.
7) سایت: http://localhost:3000
8) پنل: http://localhost:3000/admin

مهم:
- برای اجرا باید Node.js نصب باشد؛ باز کردن index.html به تنهایی کافی نیست.
- اطلاعات در data/codenova.sqlite ذخیره می‌شود و تصاویر در public/uploads قرار می‌گیرند.
- قبل از انتشار عمومی، از HTTPS استفاده کن، رمز قوی تنظیم کن و پوشه data و uploads را منظم پشتیبان بگیر.
- برای تغییر رمز مدیر، بهتر است ابزار مدیریت کاربران/تغییر رمز امن به سرور اضافه شود؛ این نسخه کاربر مدیر اولیه را از .env می‌سازد، اگر همان نام کاربری از قبل وجود نداشته باشد.
- این پروژه کد آماده راه‌اندازی است، اما هنوز روی هاست واقعی مستقر نشده است.
